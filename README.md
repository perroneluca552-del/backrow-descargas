# Backrow — Descargas

Instaladores de **Backrow**, la app para ver pelis y series con tus amigos.
Cada uno mira con su propia cuenta de Netflix, Disney+, Max, YouTube… Backrow solo sincroniza.

👉 Descargalos desde la página de Backrow o desde [Releases](../../releases/latest).

| Sistema | Archivo |
|---|---|
| Mac (M1, M2, M3, M4…) | `Backrow-Mac-AppleSilicon.dmg` |
| Mac con Intel | `Backrow-Mac-Intel.dmg` |
| Windows 10/11 | `Backrow-Windows.exe` |
| Linux | `Backrow-Linux.AppImage` o `Backrow-Linux.deb` |

**Mac:** la primera vez abrila con clic derecho → Abrir (todavía no está firmada por Apple).
**Windows:** si aparece "Windows protegió tu PC", tocá "Más información" → "Ejecutar de todas formas".

Este repositorio tiene solo los instaladores, no el código.
